# いつでも教祖様 — 完全無料・静的ウェブアプリ

APIキー不要、課金不要、外部ライブラリ不要の日本語アプリです。8カテゴリー×3説法モード×5件＝120件の手作り名言を収録。入力文のキーワードでカテゴリーを選び、説法を表示します。AIによる文章生成や高度な意味理解は行いません。

## 使い方
1. `index.html` をChrome / Safari / Edgeなどで開きます。
2. 愚痴を書き、説法モードを選んで「お告げを授かる」を押します。
3. コピーしたお告げをLINE WORKS等に貼り付けられます。お気に入りは利用中のブラウザのlocalStorageにのみ保存します。

## 仲間にURLで共有する（無料）
GitHub Pagesなどの静的サイトホスティングに、このフォルダの中身（index.html、style.css、app.js、quotes.js、assets/）をそのまま公開してください。独自ドメインは不要です。無料プランの条件・公開範囲はサービスごとに確認してください。

**注意：GitHub Pagesなどの公開URLは、合言葉を付けても本当のアクセス制限にはなりません。** 本版はパスワード認証なしです。URLを知る人が閲覧できる公開ページになるため、教祖様ご本人から写真の公開許可を得てください。非公開が必要なら認証付きホスティングなど別の構成が必要です。

## プライバシー
愚痴はブラウザ内で処理され、サーバーへ送信されません。お気に入りだけをブラウザ内に保存します。外部ホスティング利用時はホスティング事業者の通常のアクセスログ等が発生する場合があります。写真は `assets/kyoso.jpg` を差し替え可能です。

## カスタマイズ
`quotes.js` にカテゴリー別のキーワードと、kind（慈悲深い）/ spicy（辛口）/ fun（爆笑）の名言が入っています。自由に追加・変更できます。写真の公開許可がない場合は `assets/kyoso.jpg` を別の画像に差し替えてください。

## 匿名化版について
メイン画像は提供されたAI生成画像です。特定の個人名・団体名・地名を含まないよう、収録文言を見直しています。アップロードする場合、フォルダ内のファイルのみを使用し、旧版を混ぜないでください。GitHub Pagesで公開したファイルは第三者も閲覧可能です。
